# Technical Assessment - Juan Chavez Gamez

Repository containing the technical assessment solution for the Full Stack Developer position, organized into three independent sections to facilitate review and execution.

## Prerequisites
Ensure you have the following tools installed on your environment before starting:

- Git (to clone the repository)
- Node.js (v18 or higher)
- Docker Desktop / Docker Compose (to run the Fullstack app)

## Structure and Content
- Section 1 (Exercises): Algorithms and SQL queries solved using plain Node.js.
- Section 2 (Fullstack App): Task management mini-API with frontend, containerized using Docker.
- Section 3 (Theory): Theoretical questions answered in Markdown format.
